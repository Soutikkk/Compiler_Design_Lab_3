# 🖥️ Compiler Design Lab_1 Programs (Python)

A collection of **Compiler Design Laboratory programs** implemented in **Python**, covering fundamental concepts such as **Deterministic Finite Automata (DFA)**, **Lexical Analysis**, **Regular Expressions**, and **Symbol Table Management**.

These programs are intended for students studying **Compiler Design** and serve as practical implementations of important compiler concepts.

---

## 📂 Repository Contents

| File                                   | Description                                                                |
| -------------------------------------- | -------------------------------------------------------------------------- |
| `DFA Strings ending with 01.py`        | DFA to check whether a binary string ends with **01**.                     |
| `DFA Strings starting with 11.py`      | DFA to check whether a binary string starts with **11**.                   |
| `Lexical Analysis.py`                  | Basic lexical analyzer that identifies tokens from source code.            |
| `Lexical Analysis with Token Count.py` | Lexical analyzer that also counts different categories of tokens.          |
| `Regular Expression Validator.py`      | Validates input strings using regular expressions.                         |
| `Symbol Table Implementation.py`       | Demonstrates the implementation of a symbol table used in compiler design. |
